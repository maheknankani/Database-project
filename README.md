# Student GPA Portal

A modern web application for viewing and managing student GPA records. Built with Alpine.js and Express.js.

## Features

- View student GPA records by year, semester, and batch
- Modern, responsive UI
- Real-time data updates
- Clean and intuitive interface

## Tech Stack

- Frontend: Alpine.js
- Backend: Express.js
- Database: PostgreSQL (Neon)
- Styling: Custom CSS

## Setup

1. Clone the repository:
```bash
git clone https://github.com/PawanMahesh-V/Student-GPA-Sheet.git
cd Student-GPA-Sheet
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open http://localhost:4500 in your browser

## Environment Variables

Create a `.env` file in the root directory with the following variables:
```
DB_USER=your_db_user
DB_HOST=your_db_host
DB_NAME=your_db_name
DB_PASSWORD=your_db_password
DB_PORT=5432
```
